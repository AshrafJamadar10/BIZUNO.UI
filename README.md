# BizUno

A minimal, runnable React + TypeScript + Vite scaffold, mirroring the folder
structure of the original project, with a working "Hello World" demo.

## Getting started

```bash
npm install
npm run dev
```

Then open the URL Vite prints (default: http://localhost:9081).

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/app` — app entry point (`main.tsx`, `App.tsx`)
- `src/styles` — global styles
- All other folders mirror the original project's structure and are ready
  to be filled in as you build out features.
